Bagaimana Machine Learning Bekerja?

Sistem menggunakan data latih yang berisi jam belajar, kehadiran, nilai tugas, dan kategori. Algoritma KNN menghitung jarak data baru terhadap data latih, lalu memilih tiga tetangga terdekat.

Kategori yang paling banyak muncul di antara tiga tetangga tersebut menjadi hasil prediksi.

Data yang digunakan hanya data simulasi untuk pembelajaran, bukan data mahasiswa sebenarnya.
